# Package index

## Optimization

Main user-facing functions.

- [`lago_optimization()`](https://correspondmerchant.github.io/LAGO-R-Package/reference/lago_optimization.md)
  : Run a LAGO optimization
- [`visualize_cost()`](https://correspondmerchant.github.io/LAGO-R-Package/reference/visualize_cost.md)
  : Visualize and choose intervention cost functions

## Methods

Methods for the object returned by lago_optimization().

- [`print(`*`<lago>`*`)`](https://correspondmerchant.github.io/LAGO-R-Package/reference/print.lago.md)
  : Print a LAGO optimization result
- [`summary(`*`<lago>`*`)`](https://correspondmerchant.github.io/LAGO-R-Package/reference/summary.lago.md)
  : Summarize a LAGO optimization result
- [`plot(`*`<lago>`*`)`](https://correspondmerchant.github.io/LAGO-R-Package/reference/plot.lago.md)
  : Plot a LAGO optimization result

## Datasets

Datasets included with the package.

- [`BB_data`](https://correspondmerchant.github.io/LAGO-R-Package/reference/BB_data.md)
  : BetterBirth Data (for binary outcome analysis)
- [`BB_proportions`](https://correspondmerchant.github.io/LAGO-R-Package/reference/BB_proportions.md)
  : BetterBirth Data (for continuous outcome analysis, using EBP
  proportions as a continuous outcome).
- [`main_pulesa_data`](https://correspondmerchant.github.io/LAGO-R-Package/reference/main_pulesa_data.md)
  : PULESA hypertension-care data (main model)
- [`new_pulesa_data`](https://correspondmerchant.github.io/LAGO-R-Package/reference/new_pulesa_data.md)
  : PULESA hypertension-care data (new model)
